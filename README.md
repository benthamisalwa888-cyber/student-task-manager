# Student Task Manager

**Student Task Manager** est une application web de gestion des tâches destinée aux étudiants. Elle permet d'organiser les révisions, de planifier les échéances et de suivre l'avancement des tâches.

## Fonctionnalités

- Ajouter des tâches avec une date limite.
- Marquer les tâches comme terminées.
- Supprimer des tâches.
- Afficher le nombre total de tâches et le nombre de tâches terminées.
- Sauvegarder les tâches dans le navigateur grâce à LocalStorage.
- Interface responsive, adaptée aux différentes tailles d'écran.

## Technologies utilisées

- **HTML5** : structure de la page web.
- **CSS3** : mise en forme et design de l'interface.
- **JavaScript** : gestion des tâches et des interactions.
- **DOM** : manipulation dynamique des éléments HTML.
- **LocalStorage** : sauvegarde des données dans le navigateur.

## Installation et utilisation

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le fichier `index.html` dans un navigateur web.
3. Ajouter des tâches en précisant leur date limite.
4. Marquer les tâches comme terminées ou les supprimer selon les besoins.

## Objectif du projet

Ce projet a été réalisé dans le but de mettre en pratique les bases du développement web front-end, notamment la manipulation du DOM, les événements JavaScript et le stockage des données dans le navigateur.
